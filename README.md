# سكرتير واتساب محمد — Media First

مشروع أتمتة خاص يستقبل رسائل واتساب الشخصي عبر جلسة WhatsApp Web مرتبطة، ويرد بصفة المساعد الإداري الرقمي للمهندس محمد عبداللاه، مع ذاكرة محادثات محلية وتحويل العملاء الجاهزين للمعاينة أو الشراء إلى المستشار أحمد.

## ما الذي يفعله؟
- يستقبل الرسائل النصية والرسائل الصوتية الفردية.
- يفرّغ الصوت إلى نص باستخدام Gemini، ثم يحلّل الطلب ضمن سياق المحادثة.
- يرد صوتيًا على العميل عندما يرسل رسالة صوتية (ويمكن ضبطه لإرسال الصوت دائمًا أو النص دائمًا).
- يحوّل WAV الناتج من Gemini إلى OGG/Opus ويرسله كرسالة صوتية فعلية في واتساب.
- يستخدم Gemini وقاعدة معرفة محلية قابلة للتعديل.
- يحتفظ بسياق آخر الرسائل لكل محادثة محليًا.
- يحوّل طلب المعاينة أو الشراء النهائي إلى المستشار أحمد.
- يرسل لأحمد ملخصًا داخليًا بالعميل واحتياجه.
- يوقف ردوده على المحادثة بعد التحويل.
- يوفّر واجهات إدارية محمية بمفتاح Bearer.
- الرد التلقائي معطّل افتراضيًا حتى اكتمال الإعداد والاختبار.

## المتطلبات
- Node.js 22 أو أحدث.
- اتصال إنترنت مستمر.
- هاتف واتساب لربط الجلسة عبر QR.
- مفتاح Gemini API. يمكن البدء بحصة Google المجانية إن كانت متاحة لحسابك، أو ترك المفتاح فارغًا لاختبار الاتصال والرد الاحتياطي فقط.

## تشغيل Windows
1. ثبّت Node.js 22 LTS.
2. افتح Terminal داخل مجلد المشروع وشغّل:

   ```powershell
   npm install
   Copy-Item .env.example .env
   ```

3. افتح ملف `.env` واضبط:
   - `ADMIN_TOKEN`: مفتاح عشوائي طويل. للتوليد:
     `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`
   - `GEMINI_API_KEY`: مفتاح من Google AI Studio.
   - `GEMINI_AUDIO_MODEL`: نموذج فهم وتفريغ الصوت، الافتراضي `gemini-3.5-transcribe`.
   - `GEMINI_TTS_MODEL`: نموذج توليد الصوت، الافتراضي `gemini-3.8-flash-tts`.
   - `VOICE_REPLY_MODE=mirror`: يرد برسالة صوتية عندما يرسل العميل رسالة صوتية، ويرد نصيًا على الرسائل النصية. اختر `always` للصوت دائمًا أو `never` للنص فقط.
   - `VOICE_REPLY_INCLUDE_TEXT=true`: لإرسال النص بجانب الرسالة الصوتية إذا رغبت.
   - `MANAGER_PHONE`: رقم المستشار أحمد بصيغة دولية، أرقام فقط؛ مثال مصري: `2010XXXXXXXX`.
4. عدّل `knowledge/profile.md` و`knowledge/services.md` بالمعلومات المسموح للسكرتير تقديمها.
5. شغّل:

   ```powershell
   npm start
   ```

6. امسح QR الظاهر في Terminal من واتساب على الهاتف: **الأجهزة المرتبطة ← ربط جهاز**.
7. افحص الحالة من `http://127.0.0.1:3000/health`.
8. اختبر أولًا مع رقم تجريبي. بعد إضافة رقم أحمد والتأكد من الردود، غيّر `AUTO_REPLY_ENABLED=true` وأعد التشغيل.

## واجهات الإدارة
أرسل الترويسة التالية مع كل طلب إداري:

```
Authorization: Bearer YOUR_ADMIN_TOKEN
```

- `GET /health` — حالة الاتصال والإعداد.
- `GET /admin/conversations` — آخر المحادثات وحالة الإيقاف.
- `GET /admin/leads` — العملاء المحوّلون.
- `POST /admin/pause` مع `{"phone":"2010XXXXXXXX"}` — إيقاف محادثة.
- `POST /admin/resume` مع `{"phone":"2010XXXXXXXX"}` — استئناف محادثة.
- `POST /send` مع `{"phone":"2010XXXXXXXX","message":"..."}` — إرسال يدوي.

## ملاحظات مهمة
- يجب أن تظل العملية تعمل على جهاز دائم التشغيل أو خادم دائم الاتصال؛ إغلاق الجهاز يوقف الردود.
- لا يُنشر عامل WhatsApp Web على Vercel Serverless؛ الجلسة تحتاج عملية Node مستمرة ومتصفحًا وملفات جلسة محفوظة.
- بيانات الجلسة في `.wwebjs_auth` تعادل مفتاح دخول لحسابك؛ لا تشاركها ولا ترفعها إلى GitHub.
- سجل المحادثات والعملاء محفوظ محليًا داخل `data` ولا يُرفع إلى GitHub.
- المشروع يستخدم واجهة WhatsApp Web غير الرسمية؛ قد تتغير أو تتوقف، لذلك اختبر على نطاق محدود وتجنب الرسائل الجماعية أو غير المرغوبة.
- طبقة الصوت تحتاج إلى Gemini API وتخضع لحصص الاستخدام وشروط الخصوصية. صفحة التسعير الحالية تعرض حصة مجانية بلا رسوم لـ Gemini 3.8 Flash TTS، لكن الحصة والحدود قد تختلف بين الحسابات والنماذج، وقد تستخدم Google بيانات المستوى المجاني لتحسين المنتجات؛ لا تمرر بيانات حساسة قبل مراجعة الشروط.
- يحتاج توليد Voice Note إلى FFmpeg لتحويل ملف WAV إلى OGG/Opus. يعتمد المشروع على `ffmpeg-static` لتوفير الملف التنفيذي المناسب لأنظمة Windows وLinux وmacOS.
- الرد الصوتي يحاكي أسلوب محادثة طبيعيًا، لكنه يظل صوتًا مولدًا بالذكاء الاصطناعي ولا يقلّد صوت شخص حقيقي. السكرتير لا يدّعي أنه إنسان.
- يجب إضافة رقم أحمد قبل التشغيل الفعلي حتى يستلم إشعار التحويل ويظهر رقمه للعميل.


## لوحة التحكم على Vercel

تم نشر واجهة PWA على: https://media-first-secretary.vercel.app

- ثبّت التطبيق من قائمة المتصفح: Add to Home Screen / Install App.
- افتح تبويب واتساب في لوحة التحكم، وأدخل رابط HTTPS الخاص بمحرك واتساب ورمز `ADMIN_TOKEN`.
- افتح تبويب الإعدادات لإضافة Gemini API Key ورقم المستشار أحمد والتحكم في نمط الصوت والرد التلقائي.
- مفتاح Gemini يُرسل مباشرة إلى محرك واتساب ولا يُحفظ في تخزين المتصفح. رمز الإدارة لا يُحفظ بعد إغلاق الصفحة.
- يجب أن يحتوي ملف `.env` على `DASHBOARD_ORIGINS=https://media-first-secretary.vercel.app` حتى يسمح محرك واتساب للوحة بالاتصال عبر CORS.

### اتصال آمن من جهازك باستخدام Cloudflare Tunnel

1. شغّل محرك واتساب محليًا مع `HOST=127.0.0.1` و `ADMIN_TOKEN` قوي.
2. افتح نافذة طرفية ثانية وشغّل Cloudflare Tunnel المؤقت:

   ```powershell
   cloudflared tunnel --url http://127.0.0.1:3000
   ```

3. انسخ عنوان `https://...` الذي يظهر من Cloudflare إلى خانة رابط محرك واتساب في لوحة التحكم.
4. أدخل قيمة `ADMIN_TOKEN` نفسها ثم اختبر الاتصال واعرض QR.

هذا النفق المؤقت يتغير عنوانه عند إعادة تشغيله. للاستخدام المستمر أنشئ Cloudflare Tunnel ثابتًا باسم نطاق تملكه. لا تفتح المنفذ 3000 مباشرة للإنترنت.

ملاحظة: Vercel يستضيف لوحة التحكم وملفات الواجهة. عامل WhatsApp Web يظل عملية Node طويلة التشغيل على جهازك أو مضيف دائم، ولا يعمل بمجرد نشر الواجهة على Vercel.
